# Промо аукциона

15 секунд, 1920×1080, 30 fps, H.264, без звука, до 20 МБ.

Утверждённый сценарий: условия → проверка → публикация → карточка квартиры → ввод 20 200 000 ₽ → отправка → «Ставка принята». Последние две секунды неподвижны.

Все изображения получены из работающего прототипа. `capture.py` проходит реальный сценарий. `prepare.py` только кадрирует изображения; HTML `render(t)` управляет монтажом и курсором. Время ожидания растянуто для читаемости. Данные синтетические, дата зафиксирована 23 ноября 2026 года. Прототип не менялся.

Пересборка: запустить Vite, затем `PROTOTYPE_URL=http://127.0.0.1:5177 python3 motion/auction-promo/capture.py` и `python3 motion/auction-promo/prepare.py`. Проверить `verify_scene.py`, снять `render.py ... stills`, затем `render.py ... video --fmt h` из скилла product-motion. В PATH нужен каталог ffmpeg/ffprobe из `static_ffmpeg.run.get_or_fetch_platform_executables_else_raise()`.

Результат: `out/auction-promo.mp4`. Проверки: `build/scene_checks.json`, `build/media_checks.json`; контактный лист: `build/stills/sheet_h.jpg`.

Проверено: 450 кадров, ровно 15 секунд, H.264 / yuv420p / BT.709, 1 195 458 байт, звуковая дорожка отсутствует; полное декодирование без ошибок. Проверены кадры из готового MP4. Проверка типов, ESLint и 21 тест приложения прошли. Его отдельная production-сборка блокируется отсутствующим бинарным модулем `lightningcss.darwin-arm64.node` в ранее установленном node_modules; на автономный рендер ролика это не влияет.
