# Проверка подготовки · 16 ноября 2026

Окружение: macOS, Node.js 24 и 25; автоматические проверки — TypeScript, ESLint, Vitest + Testing Library, Vite. Проверка снимка: 526 токенов, 5 режимов, 24 SVG и 292 исходных файла.

Каталог проверен в браузере на 1440 × 1000 и 390 × 844: светлая и тёмная темы, варианты кнопок, поля, выбор, диалог. Escape закрывает диалог, фокус сначала переходит в поле и затем возвращается на открывшую кнопку. Горизонтального скролла на мобильном экране нет.

11 тестов: 5 общих тестов UI и 6 тестов сценариев. Проверены поиск, комбинированные фильтры и сортировка, повторный submit тех же фильтров, возврат из карточки, сохранение избранного после перезапуска, повтор после ошибки, пустая выдача, неизвестное объявление, галерея и локальная форма связи.

Production-сборка просмотрена через `npm run preview`: главная → выдача → карточка; прямое обновление вложенного маршрута; мобильная карточка, форма и уведомление о результате. В отдельной вкладке проверки ошибок и предупреждений приложения в консоли не обнаружено. Восемь объявлений и фотографии локальны; внешнего API нет.

`cian-design` прошёл `quick_validate.py`. В отдельной временной копии по инструкциям создан экран сохранённых поисков с длинным названием, удалением через подтверждение и пустым состоянием; проверка типов и поведенческий тест прошли. Пробный экран не включён в стартовый репозиторий. Это проверка использования инструкции, а не независимая оценка другим агентом.
