## Наблюдения

Desktop: два ряда навигации, контент примерно 1328 px внутри страницы 1440 px, светлая основа, насыщенные основные действия, компактные вторичные действия. Главная — фотофон и поисковый блок; выдача — фильтры, счётчик, сортировка, горизонтальные карточки; объявление — галерея, характеристики и отдельный блок цены/связи. Footer отделён тонкой линией и содержит группы текстовых ссылок.

Мобильная версия имеет отдельную композицию. В учебном приложении используются адаптивные компоненты: меню, одна колонка выдачи, перенос фильтров и перенос правой панели под содержимое. Это документированная адаптация, а не заявление о пиксельной идентичности всех мобильных экранов.

Исходный UI-kit датирован 12.11.2026; новые снимки не заменяют его автоматически. Локальные расширения компонентов и вспомогательные иконки описаны в `../README.md`.
