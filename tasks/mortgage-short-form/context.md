# Контекст: короткая ипотечная анкета

Источники: постановка дизайн-задачи и продуктовая статья «Короткая анкета», присланные Цианом 19.11.2026. Сюда не переносим внутренние номера задач, адреса, почты партнёров, API, имена сотрудников и продуктовые цифры.

## Проблема

Полная ипотечная анкета создаёт высокий барьер на раннем этапе. Пользователь уже проявил интерес — рассчитал платёж, посмотрел условия, перешёл из карточки объекта, — но ещё не готов заполнять банковскую заявку с паспортом и работодателем. Часть пользователей бросает анкету, и Циан теряет ипотечных клиентов до консультации.

Ключевая проблема: слишком рано просим данные, которые нужны для банковской заявки, но не нужны для первичной квалификации и передачи брокеру.

## Решение и гипотеза

Короткая анкета как экспериментальный флоу. Циан собирает контакты и минимум данных для первичной оценки готовности к ипотеке и маршрутизации лида. Паспорт, работодатель и документы при необходимости собирает партнёр-брокер.

**Гипотеза.** Если заменить полную анкету коротким сценарием, больше пользователей завершат заполнение. Это расширит верх ипотечной воронки: больше квалифицированных лидов, заявок в банк через партнёра, выдач и выручки.

**Две анкеты на будущее.** Короткая — для тех, кому нужна помощь и кто не хочет заполнять всё сам. Длинная — для самостоятельных пользователей, которые любят разбираться сами и не любят общаться. Полную анкету для прямой отправки в банк прорабатывают отдельно.

## Квалификация

Важно квалифицировать пользователя, чтобы не получать слишком много анкет от слабомотивированных клиентов. Для этого вопросы про сроки покупки, наличие объекта, доход и кредиты. Для высокомотивированных путь до брокера сокращается.

## Поля анкеты

| Поле | Откуда | Правило |
| --- | --- | --- |
| Фамилия и имя, отчество | Профиль Циана | Можно изменить. Отчества может не быть |
| Телефон | Профиль Циана | Нельзя изменить: подтверждён при регистрации |
| Почта | Профиль Циана | Можно изменить |
| Когда планируете покупку | Анкета | В течение месяца; 1–3 месяца; 3–6 месяцев; просто изучаю |
| Есть ли объект для покупки | Анкета | Да; нет, пока выбираю; хочу сначала понять доступный бюджет |
| Помощь консультанта с подбором объекта | Анкета | Да; нет. Только для семейной ипотеки и новостроек |
| Доход | Анкета | Быстрые кнопки или поле ввода |
| Действующие кредиты | Анкета | Да или нет |
| Платёж по кредитам | Анкета | Только если кредиты есть |
| Удобное время звонка | Анкета | Дата и время в ближайшие 3 дня |
| Согласия | Анкета | См. ниже |

**Не спрашиваем, а берём из калькулятора и контекста входа:** регион покупки, стоимость объекта, вид объекта (квартира, апартаменты, дом, машиноместо, кладовка, таунхаус), тип (новостройка, вторичка, строительство дома), ипотечная программа (семейная, IT, базовая, комбо), сумма кредита, первоначальный взнос, срок, тип занятости, зарплатный проект, готовность подтвердить доход. Банк, если пользователь пришёл из предложения конкретного банка.

**Банк пользователь не выбирает.** Брокер подбирает банк с наибольшей вероятностью одобрения и лучшими условиями.

## Согласия

- Обязательные для услуги — формулировкой «Нажимая „Продолжить“, вы принимаете эти согласия».
- Необязательные, например на рекламу, — только в явном виде, отдельной отметкой.
- Если у авторизованного пользователя уже есть согласие на рекламу, повторно не запрашиваем.
- Есть документы: оферта и согласие на рекламу.

## Экран успеха

Объясняет следующие шаги: ипотечный брокер партнёра свяжется в выбранный временной слот.

## Точки входа

- Мини-калькулятор: «Заполнить заявку на Циане» → короткая анкета.
- Основной ипотечный лендинг: «Заполнить заявку на Циане» → короткая анкета.
- Старый ипотечный калькулятор: «Подать заявку онлайн» → короткая анкета.
- Приложение: «Отправить заявку» → короткая анкета.
- Кнопка под ценой в карточке объекта и остальные ипотечные точки → основной ипотечный лендинг.

## Ограничения и пограничные случаи

- Новую анкету пользователь может отправить, только когда предыдущая получила конечный статус: выдана, отменена или отказ. Нужен сценарий для пользователя с активной заявкой.
- В макетах должны быть пограничные случаи, экраны состояний и экраны деградации — это требование готовности задачи.
- Задача на все платформы. В задаче участвует редактор.

## Эксперимент и метрики

A/B-тест: контроль — полная анкета, тест — короткая. Все платформы и все текущие точки входа.

Метрики:

- отправленные анкеты;
- брошенные анкеты — цель: статистически значимо снизить их долю в тестовой группе;
- уровень дозвона — колл-центр Циана и партнёр;
- конверсия из отправленной анкеты в заявку в банк.
